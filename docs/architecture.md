# Архитектура — v0.1

**Статус:** каркас, технические решения могут измениться до первого продуктового спринта.

- React/TypeScript — недоверенный клиент, только отображение и отправка запросов.
- NestJS — модульный монолит. В каждом модуле `commands/`, `queries/`, `domain/`, `infra/`.
- CQRS логически разделяет пути записи и чтения; отдельные физические базы на старте не нужны.
- PostgreSQL — финансовые данные и права владения; в API пока нет подключения к базе.
- Transactional outbox — план: запись события вместе с бизнес-транзакцией, затем доставка worker'ом.
- Background AI worker — план: прогнозы на сервере, LLM через провайдерский API при необходимости. Доступ ограничен разрешениями пользователя.
- Банковские коннекторы — отдельные адаптеры для поддерживаемых официальных API и импорта; никаких банковских паролей, Playwright не входит в базовую архитектуру.
- Монолит сначала: модули не читают чужие таблицы напрямую, события и внешние API версионируются. Выделение сервисов впоследствии потребует адаптации транзакций, инфраструктуры и консистентности.

## Целевые границы

`web -> HTTP API -> command/query handlers -> domain -> repositories -> PostgreSQL`

`domain event -> outbox -> worker -> AI job / integration`

## Что реально реализовано

Только API с healthcheck, CQRS QueryBus и заглушкой GET /api/accounts, без реальных счетов, auth, БД и AI.
