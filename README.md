# Бюджето — hackathon

Серверное приложение для учёта личных финансов с возможностью фонового AI-анализа.

## Архитектурная основа
- Web: React + TypeScript (подключим интерфейс существующего Budgeto отдельной задачей).
- API: NestJS, модульный монолит, CQRS (раздельные команды и запросы).
- PostgreSQL: финансовые данные, изоляция по пользователям.
- Асинхронные задачи: worker; очередь и Redis подключаются при появлении задач.
- Банки: адаптеры импорта (Excel/CSV) и официальных API, без хранения банковских паролей.
- AI: обработчик с минимальными разрешениями, без прямого неограниченного доступа к БД.

## Состояние
Это **начальный каркас**, не готовый продукт. Существующий проект [Budgeto](https://github.com/xom9kxom9k/Budgeto) — источник функциональности для переноса, не импортирован автоматически.

## Локальный запуск API
```bash
npm install
npm run migration:run
npm run dev:api
```
Проверка: `GET http://localhost:3000/api/health`.

## PostgreSQL (локально)
```bash
docker compose up -d postgres
npm run migration:run
```
API использует PostgreSQL без `synchronize`; схема создаётся только через миграции.

Entity-классы принадлежат своим модулям: auth-сущности находятся в
`apps/api/src/modules/auth/entities`, а `AccountEntity` — в
`apps/api/src/modules/accounts/entities`. Папка `database` содержит только
DataSource и миграции.

Подробности: [архитектура](docs/architecture.md), [безопасность](docs/security.md), [бэклог](docs/backlog.md).

## Демо аналитики и накоплений

После локальных миграций и запуска API выполните `npm run seed:demo` (Node.js 22.18+).
Для другого локального порта задайте `DEMO_API_URL`, например `http://127.0.0.1:3001/api/`.
Скрипт разрешает только локальный адрес и блокирует запуск в production.

Создаётся отдельный аккаунт `demo.analytics@budgeto.local`: три счёта, категории
доходов и расходов, операции за два завершённых месяца и текущий месяц, цель накоплений.
Повторный запуск использует те же идентификаторы операций и проверяет отсутствие дублей,
целостность подписанного журнала и совпадение графика с итогами. Ограничение частоты
запросов сохраняется: скрипт может подождать минуту.

Локальные пароль, секрет 2FA и фраза Vault находятся в `.data/demo/analytics.json`;
этот файл исключён из Git. Код для входа: `npm run demo:code`.
На странице обзора выберите «Прошлый месяц», чтобы увидеть заполненный график и прогноз.
Цель хранится в аккаунте отдельно для каждой валюты; уже отложенную сумму пользователь
обновляет вручную. Прогноз использует средний остаток выбранного завершённого периода
от 14 дней и предполагает, что весь остаток пойдёт на цель. Переводы и отмены исключены;
конвертации валют нет.
